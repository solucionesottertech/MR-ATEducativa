# Guía de Link Building — MR Ateducativa

## ¿Qué es el link building?

El link building es el proceso de conseguir que otros sitios web enlacen hacia mr-ateducativa.cl. Cada enlace (backlink) es como un "voto de confianza" para Google: cuantos más votos de calidad tengas, mejor posicionado estarás en los resultados de búsqueda.

## Orden de implementación recomendado

### Semana 1: Fundaciones (01-Directorios)
- [ ] Regístrate en los 15 directorios de la lista
- [ ] Asegúrate de que NAP (Nombre, Dirección, Teléfono) sea idéntico en todos
- [ ] Tiempo estimado: 2-3 horas

### Semana 2-3: Contenido Pillar (02-Contenido-Pillar)
- [ ] Revisa y personaliza el artículo propuesto
- [ ] Publícalo en el blog de mr-ateducativa.cl (necesitas crear sección /blog)
- [ ] Compártelo en LinkedIn y redes sociales
- [ ] Tiempo estimado: 4-6 horas

### Semana 3-4: Outreach (03-Outreach)
- [ ] Identifica 10 blogs/instituciones de la lista
- [ ] Personaliza los templates con datos específicos de cada destino
- [ ] Envía 3-5 emails por semana (no más, para no parecer spam)
- [ ] Tiempo estimado: 2 horas por semana

### Mes 2: Recursos gratuitos (04-Recursos-Gratuitos)
- [ ] Diseña los recursos en Canva o con un diseñador
- [ ] Crea páginas de descarga en el sitio (con formulario de email)
- [ ] Promociona en redes y outreach
- [ ] Tiempo estimado: 8-10 horas (incluye diseño)

### Mes 3+: Universidades (05-Universidades)
- [ ] Identifica universidades objetivo
- [ ] Prepara propuesta de convenio
- [ ] Agenda reuniones con coordinadores de práctica
- [ ] Tiempo estimado: continuo, resultados a 3-6 meses

## Reglas de oro

1. **Calidad > Cantidad**: Un enlace de un sitio educativo chileno (.cl o .edu) vale más que 100 de directorios genéricos
2. **NAP consistente**: Nombre, dirección y teléfono deben ser idénticos en todos los registros
3. **Anchor text variado**: No uses siempre "MR Ateducativa" como texto del enlace. Varía con "asesoría educativa Chile", "ATE Santiago", etc.
4. **Paciencia**: El link building tarda 3-6 meses en mostrar resultados medibles en SEO
5. **Nunca compres enlaces**: Google penaliza sitios que compran backlinks
